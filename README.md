## 🎯 About The Project

**ColdTech** is a stunning 3D interactive beverage showcase that combines cutting-edge web technologies with photorealistic 3D rendering. This project demonstrates the power of **Three.js**, modern CSS, and creative JavaScript to deliver an immersive brand experience.

> **"We debug hot code and serve cold drinks"** - Because great developers deserve great refreshments! 😎

### ✨ Why ColdTech?

- 🎨 **Photorealistic 3D Cans** - Using Three.js PBR materials
- 🌈 **Interactive Animations** - Smooth transitions and effects
- 📱 **Fully Responsive** - Works on all devices
- 🚀 **Optimized Performance** - GPU-accelerated rendering
- 🎭 **Brand Storytelling** - Each beverage has its own story
- 🎪 **Created Just For Fun** - Because coding should be enjoyable!

## 🎮 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of web development (optional)
- Love for cold beverages! 🧊

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sonu93418/Cold-Tech.git
   ```

2. **Navigate to the project**
   ```bash
   cd Cold-Tech
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your favorite browser
   # Or use a local server:
   npx serve
   # Or
   python -m http.server 8000
   ```

4. **Enjoy! 🎉**
